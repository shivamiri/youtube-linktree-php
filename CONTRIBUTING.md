# Contributing

Thanks for your interest! This project is beginner friendly.

## How to contribute

1. Fork this repository.
2. Create a branch for your change (`git checkout -b my-fix`).
3. Make your change and check every PHP file with `php -l filename.php`.
4. Open a Pull Request and describe what you changed and why.

## Rules

- Keep it working on plain shared hosting (PHP 8+, MySQL). No Composer packages, no frameworks, no build steps.
- Never commit `common/config.php` or any real database credentials, API keys or secrets.
- Keep the mobile-first dark design consistent.
- Small, focused pull requests are easier to review than big ones.

## Reporting bugs

Open an issue with the bug report template: what you did, what happened, what you expected, your PHP version and hosting.

## Ideas

Not sure what to work on? Check the Roadmap section in the README or the open issues.
